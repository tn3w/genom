Crate genom

Fast offline reverse geocoding. Turns coordinates into the nearest city with its region, district, postal code, timezone and a full set of country facts.

Features

  • One call - genom::lookup(lat, lon)
  • 38 fields - city, population, elevation, postal code, timezone, currency, languages, neighbours and more
  • Exact - true nearest city, correct at high latitudes and across the antimeridian
  • Fast - about 10 µs per lookup on land, nothing to parse at startup
  • Offline - the database is built at compile time and embedded in your binary

Quick Start

if let Some(place) = genom::lookup(48.8566, 2.3522) {
    println!("{} {}, {}", place.postal_code, place.city, place.country.name);
    println!("{} ({})", place.timezone.name, place.timezone.abbreviation);
}

Struct Geocoder

A reverse geocoder over a geo.bin database: the embedded one, a file on disk, or any byte buffer. It is Send + Sync; lookups never lock.

Reference Command line 

genom 48.8566 2.3522            # look up with the embedded database
genom 48.8566 2.3522 geo.bin    # look up with a database file
genom build geo.bin             # build a database file

build reads sources from ./data/ when present and otherwise downloads them next to the output file. lookup.py in the repository is a dependency-free Python reader for the same file.

Reference Binary format

geo.bin is one little-endian file read in place: no parsing, no index building, no unsafe code. Every section starts at a 4-byte boundary.

Header (17 × u32)

  1. magic "GEO2"
  2. string count, string offsets, string bodies
  3. country count, columns per country, country table
  4. city layer: cell count, directory, records, cells per degree, fields per record
  5. postal layer: same five words

Sections

  • Strings - every text value interned once; u32 offsets into UTF-8 bytes
  • Countries - 18 u32 per country: 16 string ids, EU flag, postal code count
  • Directory - sorted (cell, offset) pairs, binary-searched in place
  • Records - per cell: count, then zigzag-delta microdegree coordinates and varint fields

Lookup

Rings of grid cells are scanned outward from the query. The search stops once no unscanned cell can hold anything closer, measuring longitude scaled by cos(latitude) and wrapping at ±180°. The postal search is limited to the city's country.
