why genom

built for developers who need speed and precision

⚡

blazing fast

Exact nearest-neighbour ring search over a spatial grid, read straight from an embedded binary with zero parsing at startup.

🎯

rich data

38 fields per location: city, population, elevation, postal code, district, timezone, DST, currency, languages, neighbours and more. Everything in one call.

🔧

zero setup

Database builds automatically on first install. No downloads, no configuration files, no external dependencies. Just add and use.

🧵

thread-safe

Global singleton with lazy initialization. Lock-free reads mean zero contention in multi-threaded applications. Safe by default.

installation

Add genom to your Cargo.toml and start converting coordinates to location data immediately.

1
Add dependency
2
Import library
3
Start looking up
Cargo.toml
[dependencies]
genom = "VERSION_CUT"
main.rs
use genom;

let place = genom::lookup(40.7128, -74.0060)?;
println!("{}", place.timezone.name);
